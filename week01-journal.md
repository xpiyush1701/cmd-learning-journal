5 hours

## Content Insights
- This week, I focused on creating a static website for my startup, NutritionAI. I learned that HTML provides the structure for a webpage, while CSS is responsible for styling and layout. By separating the two, it ensures better maintainability and flexibility in updating the site.
- GitHub Pages was introduced as a convenient platform for hosting static websites. The documentation helped me understand how to push changes to a repository and have them reflected on the live site automatically, which is a great feature for ongoing development.
- While I successfully set up the basics of the website and attempted to push it to GitHub Pages, I encountered issues with the deployment. Initially, I faced problems with linking my HTML and CSS files correctly, and the website didn’t display as expected on the live site. I learned the importance of file structure and how small mistakes like incorrect file paths can cause issues. 
- Although the website didn’t fully work at first, troubleshooting this issue taught me how to use GitHub effectively to track changes, commit them, and push updates to the live site. It also showed me the significance of testing every change locally before pushing it to avoid errors.

## Career/Employability/Learning Insights
- I learned that understanding web development fundamentals, especially HTML and CSS, is essential for creating professional-looking websites. These are skills that are often required in both front-end web development and digital marketing roles. I found that organising my time between coding and reviewing tutorials helped me retain the information more effectively.
- From a career perspective, the process of setting up a website from scratch gave me insight into how important it is to consider user experience (UX) and accessibility. These principles are vital when building digital products, especially for an audience that may rely on accessible designs.
- I also realised that mistakes, such as deployment errors, are an unavoidable part of learning. In the workplace, problems will occur, and the ability to troubleshoot and adapt is a great skill. Even though the deployment wasn’t fully successful, I now have a better understanding of how to work with GitHub Pages and the steps needed to get a website live.
- One key takeaway is the value of continuous learning. I have noticed that breaking down complex tasks into manageable steps and tackling them one at a time is a good strategy to stay focused and motivated. This method will be crucial as I continue to develop my web development skills, especially for more challenging tasks in the future. The process of working through the deployment challenge made me more confident in my ability to solve problems and find solutions, even when things don’t go according to plan.
